# Todo Manager

Простой менеджер задач на React.

## Функционал

- добавление, удаление и редактирование задач
- отметка выполненных
- фильтрация (все / активные / выполненные)
- тёмная тема
- сохранение в localStorage

## Запуск

```bash
npm install
npm run dev
```

## Деплой

```bash
npm run deploy
```
